# Contributing

Thanks for helping improve this resource list.

## What To Add

- Benchmark papers
- Survey and roadmap papers
- Official engineering reports on coding agents
- Open-source coding-agent systems
- High-signal documentation on workflow integration, harness design, review, CI, and deployment

## Contribution Rules

- Prefer original papers, official docs, or official repositories.
- Keep each addition concise.
- Avoid duplicate links.
- Keep categories workflow-oriented instead of vendor-oriented.
- Use neutral wording and avoid hype.

## Pull Request Checklist

- The resource is directly relevant to coding agents or agentic software engineering.
- The link points to a stable primary source.
- The item is placed in the best-fitting section.
- The wording is short, factual, and easy to scan.
